# Limitless Fitness React homepage demo

Responsive React + Vite concept inspired by the supplied reference image. This is an independent concept, not the official gym website.

## Run
1. Install Node.js.
2. Extract the ZIP and open the folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed by Vite.

## Build
Run `npm run build`; deploy the `dist` folder to Vercel or Netlify.

## Before presenting
- Replace remote Unsplash images with gym-approved photos.
- Verify all gym details and contact information.
- The contact button opens an email draft; it does not store enquiries.
- No booking, payment, admin panel, or backend is included.
- Images and Google Fonts need an internet connection.
